# N0ctis-17

An original browser ARG-style puzzle experiment.

## Design

N0ctis-17 is built around a simple rule:

> Never confuse a correct answer with an understood question.

The opening three questions are deliberately easy. They are calibration, not the main challenge.

The real puzzle begins with:
- visual extraction from a signal board
- a self-contradicting logic system
- meta-reasoning about the framing of the puzzle
- an expanding hidden narrative

The project is intentionally fictional and self-contained. It does not provide instructions for compromising real systems.

## Run

Open `index.html` directly for the simplest test, or serve the folder through any static HTTP server.
